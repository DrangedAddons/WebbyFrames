# Webby Frames

Retail-style player, target, target of target and focus frames for WoW Forever, built from Blizzard's own unit frame art
(gold ring with the pointed corner, pointed bars). Nothing else is needed.

## Install
Unzip the `WebbyFrames` folder into `World of Warcraft/_classic_beta_/Interface/AddOns`
(delete any older `DFFramesForever` or `WebbyFrames` folder first; settings carry over).

## Use
- `/webby` opens the settings: General, Player, Target, Focus.
- `/webby edit` opens Edit Mode. Drag the frames; each has a dialog with scale, portrait side, name, bar text and colours.
- `/webby reset` resets all four frames.
- Everything is saved per Edit Mode layout.

## Options per frame
- Scale, portrait side (target/focus), show name
- Bar text: always / on mouseover / off, and totals / percentages / both
- Health colour: class colour in PvE and reaction colour in PvP (default), always class, always reaction, or a health gradient
